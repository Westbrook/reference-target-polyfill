Behavior & limits

Reference Target does not copy a host’s attributes. String ID references stay in their own tree, so neither negative button reaches the outside panel.

The positive example assigns popoverTargetElement directly. This native outward element reflection works independently of Reference Target. Inspect the inner button’s accessible name separately from its host.

Code sample

Assign the outside element directly.

const host = document.getElementById('bd-positive-host');
const button = host.shadowRoot.getElementById('button');
const panel = document.getElementById('bd-positive-panel');

// An outward element reference, independent of Reference Target.
button.popoverTargetElement = panel;
